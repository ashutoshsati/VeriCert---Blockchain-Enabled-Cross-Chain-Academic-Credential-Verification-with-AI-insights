## Brand & Style

The design system establishes an institutional-grade, cryptographic visual language for enterprise data interfaces, multi-signature treasury dashboards, and risk analytics suites. The aesthetic merges stealth luxury with high-frequency technological precision, addressing institutional Web3 operators, quantitative risk officers, and enterprise compliance executives.

The visual style synthesizes **Minimalism** and **Refined Glassmorphism** against a foundational canvas of matte charcoal and obsidian tones. Surfaces reject high-gloss consumer gradients in favor of micro-textured depth, luminous accent borders, and structural wireframe clarity. The emotional outcome must project unshakeable cryptographic verification, rigorous architectural security, and effortless command over complex on-chain telemetry.

## Colors

The palette relies on deliberate tonal pacing across deep black spectra to ensure data density remains legible without cognitive strain:

- **Base Architecture**: The lowest viewport foundation begins at `#121214` (Obsidian Canvas), elevating into `#18181b` (Matte Surface) for structural modules and `#202024` (Elevated Panel) for floating overlays or data drawers.
- **Structural Contrasts**: Structural divisions abandon blurry raster lines in favor of 1px crisp demarcations using `#27272a` for resting state panels and `#3f3f46` for interactive component borders and table dividers.
- **Verification Accents**: `#10b981` (Cryptographic Emerald) anchors primary interactive triggers and affirmative state displays. `#34d399` (Mint Glow) provides subtle ambient backdrops, highlight states, and active telemetry strokes. `#059669` serves as the high-contrast pressed/dark-accent foundation.
- **Institutional Authority**: `#f59e0b` (Muted Amber) functions strictly as a tertiary signal for credential validation badges, multi-signature thresholds, hardware attestation seals, and elevated security warnings.
- **Typography & Content**: Headlines demand pure, crisp optical punch via `#f4f4f5` (Zinc 100), while body and tabular telemetry leverage `#a1a1aa` (Zinc 400) to maintain strict typographic hierarchy without harsh glare. Inactive states and secondary micro-copy rest at `#71717a` (Zinc 500).

## Typography

The typographic hierarchy implements three distinct type engines tailored for institutional fintech workflows:

- **Display & Headlines (Space Grotesk)**: Chosen for its mathematical cadence and geometric tech posture. Use for operational metrics overviews, section headings, and primary KPI anchors.
- **Narrative & Core Interface (Geist)**: Delivers surgical legibility across dense data tables, execution logs, and configuration trees without drawing visual attention to its own glyphs.
- **Telemetry & Verification Data (JetBrains Mono)**: Reserved for transaction hashes, block indices, cryptographic wallet paths, timestamps, tabular calculations, and status pill signifiers. All monospace elements use optical letter spacing adjustments to ensure zero glyph collisions across rapid refresh loops.

## Layout & Spacing

The architecture operates on an adaptive 12-column fluid grid system pinned to a maximum canvas bounds of 1680px for widescreen command monitors, flexing proportionally downward to single-column stacking for tablet and mobile verification handoffs.

- **Grid Alignment**: 12 columns with `1.25rem` (20px) gutters on desktop, compressing to 6 columns at 1024px tablet viewports, and 4 columns with `0.75rem` (12px) gutters under 640px.
- **Canvas Boundaries**: Base viewport margins sit at `2rem` (32px), locking dense telemetry screens to high display utility while providing an intentional cushion against browser frames.
- **Rhythm Principle**: Component spacing enforces strict multiples of 4px. Metric readouts, chart headers, and control ribbons utilize `space-md` gaps, while compact data tables leverage `space-xs` and `space-sm` cell boundaries to maintain executive-level information density.

## Elevation & Depth

Depth is established strictly through tonal layering and micro-luminance rather than heavy structural shadows, ensuring absolute visual sharpness across OLED and high-resolution enterprise displays:

- **Canvas Tier (Level 0)**: `#121214` solid matte base. Never receives shadows or borders.
- **Card & Component Tier (Level 1)**: `#18181b` surface bounded by a razor-thin 1px border of `#27272a`. Elevated with an imperceptible, diffuse dark falloff: `0 4px 20px -2px rgba(0, 0, 0, 0.5)`.
- **Floating & Interactive Tier (Level 2)**: Modals, parameter dropdowns, and context tooltips employ `#202024` with a 1px border of `#3f3f46`. Dropdowns receive an ambient edge glow: `0 10px 30px -4px rgba(0, 0, 0, 0.8), 0 0 0 1px rgba(255, 255, 255, 0.05)`.
- **Active / Cryptographic Focus**: Selected nodes, verified transactions, and focused inputs trade standard drop shadows for an exterior 1px aura: `0 0 12px 0 rgba(16, 185, 129, 0.25)`.

## Shapes

The design uses **Soft (Level 1)** corner geometry. Standard UI components, data tables, metrics panels, and inputs utilize `0.25rem` (4px) corner radii. Structural cards and container boundaries use `rounded-lg` (`0.5rem` / 8px), and primary application viewports use `rounded-xl` (`0.75rem` / 12px).

This tight, calibrated roundness maintains mathematical rectilinearity—echoing hardware terminal interfaces and cryptographic certificates—while preventing abrasive visual edges across tiled grid arrangements. Pill shapes (`9999px`) are strictly restricted to state-indication chips and audit tags.

## Components

### Primary & Secondary Buttons
- **Primary Action (Commit / Execute)**: Solid `#10b981` background, `#121214` heavy-contrast typography (`JetBrains Mono`, 12px, weight 600, uppercase). Rest border: transparent; hover adds a subtle `#34d399` micro-sheen: `box-shadow: 0 0 14px rgba(16, 185, 129, 0.4)`. Active state drops to `#059669`.
- **Secondary / Stealth Action**: `#18181b` background with a 1px `#27272a` outline. Label color is `#f4f4f5`. Hover state elevates the border to `#3f3f46` with a `#202024` surface fill.
- **Destructive / Slash Action**: `#18181b` surface with a 1px outline of `#7f1d1d`. Label color is `#f87171`. Hover transitions surface to `#450a0a`.

### Cards & Analytical Containers
- Built on `#18181b` backing with a persistent 1px `#27272a` contour.
- Top-level metric cards display an optional top-edge verification hairline (1px solid `#10b981` at 40% opacity) signifying healthy stream sync.
- Padding adheres strictly to `space-lg` (24px) for desktop analytics blocks and `space-md` (16px) for compact sidebar telemetry.

### Input Fields & Select Controls
- Base canvas: `#121214` with a 1px border of `#27272a`.
- Typography: `#f4f4f5` text with placeholder locked to `#71717a`.
- Hover updates border to `#3f3f46`.
- Focus triggers a 1px border of `#10b981` accompanied by a localized aura: `box-shadow: 0 0 0 1px #10b981, 0 0 8px rgba(16, 185, 129, 0.2)`.

### Chips & Verification Pills
- Standard height: 20px, radius: 9999px, typography: `JetBrains Mono` at 10px uppercase.
- **Verified Status**: Background `rgba(16, 185, 129, 0.1)`, 1px border `rgba(16, 185, 129, 0.3)`, text `#34d399`. Contains a 4px solid `#10b981` glowing pulsing dot.
- **Quorum / Multi-Sig Warning**: Background `rgba(245, 158, 11, 0.1)`, 1px border `rgba(245, 158, 11, 0.3)`, text `#f59e0b`.

### Checkboxes & Radios
- Box width and height: 16px, corner radius: 3px (checkbox) or circular (radio).
- Rest state: `#121214` fill with 1px border `#3f3f46`.
- Checked state: `#10b981` fill with an internal `#121214` icon marker and zero outer glow unless actively focused via keyboard.

### Data Tables & Execution Lists
- Header rows utilize `#121214` with a bottom border of 1px `#27272a`. Typography is uppercase `JetBrains Mono` (11px, `#71717a`).
- Table rows rest on transparent backgrounds, separating via 1px `#1c1c20` borders. Hover state shifts row to `#1a1a1e`.
- Numerical columns right-align with monospace tabular figures (`font-variant-numeric: tabular-nums`).

### Cryptographic Identity Displays (Specialized Component)
- Embedded truncation modules for address strings (`0x4A...9b2C`).
- Rendered in `#202024` pill containers with 1px `#27272a` outlines, integrating a one-click copy trigger that flashes an emerald confirmation aura (`#10b981`) upon execution.
